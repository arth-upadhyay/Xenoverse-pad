
## how to run it 

just download the apk and the .exe file 

make sure the usb debugging is on for the usb connecting for playing otherwise it work 

without usb debugging on you can still play it using wifi. just connect the pc and phone to the same wifi network

find your ipv4 from the cmd just type "ipconfig" and look at the ipv4 and copy it in the apk 
and the ip address is not needed if its connected via usb 

## RECOMMENDED SETTINGS

make sure the usb is plugged in and the wifi is also connected at the same time

because of that it will be able to help with the input lag which you will face if the usb cable is disconnected 

##what is needed to run it 

Ensure [ViGEmBus] is installed on your PC. or just copy this in your browser (https://github.com/nefarius/ViGEmBus/releases)

Install ADB and ensure it is in your system PATH for USB playing.
